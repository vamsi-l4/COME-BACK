## Important Patterns

### Maximum Tracking

Keep the largest value seen so far.

### Minimum Tracking

Keep the smallest value seen so far.

### Accumulator

Maintain a running total.

### Counter

Increase a value when a condition is satisfied.

### Build Result

Create a new list and add required elements.

### Seen Tracking

Remember elements that have already appeared.

### Multiple Variables

Some problems require tracking more than one value,
such as largest and second largest.

## Problem-Solving Process

1. Understand the problem
2. Identify input
3. Identify output
4. Take a small example
5. Identify what information must be remembered
6. Decide variables
7. Write the approach
8. Dry run
9. Code
10. Test edge cases
