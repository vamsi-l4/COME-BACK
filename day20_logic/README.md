# Day 21 — Recursion Practice and Problem Solving

## Goal

Practice recursion by solving number and string problems. Focus on understanding the logic before writing code.

## Prerequisites

- Function basics
- Base case
- Recursive case
- Function call sequence
- Dry-running recursive calls

## Problems

### 1. Sum of Digits
Find the sum of all digits in a number.

Example: `1234` → `10`

File: `01_sum_of_digits.py`

### 2. Count Digits
Count the number of digits in an integer.

Example: `456` → `3`

File: `02_count_digits.py`

### 3. Reverse a String
Reverse a string using recursion.

Example: `"cat"` → `"tac"`

File: `03_reverse_string.py`

### 4. Palindrome Using Recursion
Check whether a string reads the same forward and backward.

Example: `"madam"` → `True`

File: `04_palindrome_recursion.py`

### 5. Power of a Number — Optional
Calculate a number raised to a non-negative integer exponent.

Example: `power(2, 4)` → `16`

File: `05_power_of_number.py`

## Problem-Solving Method

For each problem:

1. Understand the question.
2. Identify input and output.
3. Work through a small example.
4. Identify the base case.
5. Identify the recursive case.
6. Dry-run the calls on paper.
7. Write the Python solution independently.
8. Test normal cases and edge cases.
