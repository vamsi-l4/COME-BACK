# Day 10 - Two Pointers

## Goal

Learn how two positions can move through a sequence and avoid unnecessary repeated checking.

## Topics

- Two Pointers
- Left and Right Pointer
- Slow and Fast Pointer
- Opposite-End Traversal
- Sorted Array Logic
- In-Place Processing
- Pointer Movement
- Dry Run

## Problems

1. Reverse String
2. Valid Palindrome
3. Two Sum II
4. Remove Duplicates from Sorted Array
5. Move Zeroes
6. Squares of a Sorted Array - Optional

## Pattern 1 - Opposite Ends

Start:

left = beginning
right = end

Useful for:

- Reverse String
- Palindrome
- Pair problems in sorted arrays

## Pattern 2 - Slow and Fast

fast = scans values
slow = tracks/builds useful result

Useful for:

- Remove Duplicates
- Move Zeroes

## Important Questions

- Where should pointers start?
- What does each pointer represent?
- When should each pointer move?
- Why is that movement correct?
- When should the loop stop?

## Main Learning

Two pointers are useful when two positions can move intelligently through a sequence instead of checking every possible combination.
