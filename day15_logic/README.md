# Day 17 - Prefix Sum

## Goal

Understand cumulative sums and efficient range-sum reasoning.

## Topics

- Running Sum
- Prefix Sum
- Range Sum
- Pivot Index
- Subarray Sum

## Main Patterns

Running Sum:
Keep cumulative total.

Range Sum:
Prefix[right] - prefix[left - 1]

Pivot:
Right = Total - Left - Current

Subarray:
Continuous portion of an array.
