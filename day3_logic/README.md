## Important Patterns

### Counter

A variable used to count something.

Example:

count = 0

### Accumulator

A variable used to continuously build a result.

Examples:

sum = 0
product = 1

### Flag

A variable used to remember whether something happened.

Example:

found = False

### Condition + Loop

Repeat an operation and check a condition each time.

### Digit Processing

Extract a digit → process it → remove it → repeat.

### Edge Case

A special input that requires separate consideration.

## Problem-Solving Process

1. Understand the input
2. Understand the output
3. Take a small example
4. Observe the pattern
5. Identify the rule
6. Decide required variables
7. Write the approach
8. Dry run
9. Write code
10. Test edge cases
