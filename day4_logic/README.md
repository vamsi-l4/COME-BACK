## Important Patterns

### Character Traversal

Process one character at a time.

### Counter

Used when we need to count occurrences.

### Condition + Counter

Check each character and increase the counter when the condition is true.

### Build Result

Start with an empty string and add characters that should be kept.

### Compare

Compare the original string with a processed version.

## Problem-Solving Process

1. Understand input
2. Understand output
3. Take a small example
4. Observe what changes
5. Identify the rule
6. Decide variables
7. Write approach
8. Dry run
9. Code
10. Test edge cases

## Main Learning

A string can be processed one character at a time.
The same logic patterns used for numbers can be applied to strings.
