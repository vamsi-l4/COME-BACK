# Day 18 — Linked List Problems

## Goal

Learn four linked list problems by understanding the logic before writing code.

## Topics Covered

### 1. Find Middle Node
- Understand slow and fast pointers.
- Slow moves one step.
- Fast moves two steps.
- Find the middle without counting all nodes first.

File: `01_middle_node.py`

### 2. Remove Linked List Elements
- Remove all nodes matching a target value.
- Handle removal from the middle.
- Handle removal from the head.
- Return the updated head.

File: `02_remove_elements.py`

### 3. Linked List Cycle
- Understand how a linked list can contain a loop.
- Use slow and fast pointers.
- Detect whether both pointers meet at the same node.

File: `03_linked_list_cycle.py`

### 4. Merge Two Sorted Lists
- Compare the current values of two sorted lists.
- Select the smaller value at each step.
- Keep the merged list sorted.
- Connect any remaining nodes.

File: `04_merge_sorted_lists.py`

## Problem-Solving Method

For every problem:

1. Read and understand the question.
2. Identify the input and expected output.
3. Work through a small example.
4. Identify the information and pointers to track.
5. Explain the approach in simple English.
6. Dry-run the approach step by step.
7. Write the Python code.
8. Test normal cases and edge cases.


## Completion Goal

I should be able to explain the logic, write the solution, and test each problem independently.
