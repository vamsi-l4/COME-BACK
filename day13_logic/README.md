## Goal
Learn how to search efficiently.

## Topics
- Linear Search
- Binary Search
- Search Insert Position
- First Bad Version

## Main Patterns

Linear Search:
Check one by one.

Binary Search:
Sorted data → middle → eliminate half.

Boundary Search:
Find first position where condition changes.
