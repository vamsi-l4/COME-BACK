# Day 20 — Recursion

## Goal

Understand recursion from the basics and solve beginner-level problems without directly copying code.

## Concepts

- Meaning of recursion
- Base case
- Recursive case
- Function call sequence
- Dry-running recursive calls

## Problems

1. Print numbers from N to 1
2. Print numbers from 1 to N
3. Calculate factorial of N
4. Calculate the sum of N natural numbers
5. Understand and implement basic Fibonacci recursion

## Problem-Solving Method

For every problem:

1. Understand the question.
2. Identify input and expected output.
3. Work through a small example.
4. Identify the base case.
5. Identify the recursive case.
6. Dry-run the function calls.
7. Write the Python solution independently.
8. Test normal and edge cases.
