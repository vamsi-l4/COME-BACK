## Main Pattern

If the most recently added/opened item
must be handled first:

Think STACK.

## Stack Operations

Push:
add item to top

Pop:
remove top item

Top:
look at most recent item

## Valid Parentheses

Opening bracket:
push

Closing bracket:
check top

If matching:
pop

If not matching:
False

At the end:
empty stack = valid
