# Day 8 - Dictionary

## Goal

Learn how to store and retrieve information while solving
problems.

## Topics

- Dictionary
- Key
- Value
- Lookup
- Frequency counting
- Frequency map
- Seen information
- Grouping
- Multiple-pass problems

## Problems Practiced

1. Character Frequency
2. Number Frequency
3. First Unique Character
4. Two Sum
5. Majority Element
6. Basic Grouping

## Important Patterns

### Frequency

item → count

Used when we need to know how many times something appears.

### Lookup

item → information

Used when we need to quickly find stored information.

### Grouping

category → list of items

Used when multiple items belong to the same category.

### Multiple Pass

First pass:
Collect information.

Second pass:
Use the collected information.

## Problem-Solving Process

1. Understand the problem
2. Identify input
3. Identify output
4. Take a small example
5. Ask what information must be remembered
6. Decide key and value
7. Identify the pattern
8. Write the approach
9. Dry run
10. Code
11. Test edge cases
12. Debug

## Main Learning

A dictionary is useful when a problem requires
remembering information about values.

The key identifies the item and the value stores
the information needed about that item.
