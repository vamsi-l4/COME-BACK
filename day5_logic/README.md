## Important Patterns

### Frequency

Store how many times each character occurs.

character → count

### Seen

Remember whether a character has already appeared.

### Counter

Used to count occurrences.

### Build Result

Process characters and add only the required characters.

### Multiple Pass

First pass:
Collect information.

Second pass:
Use that information to make a decision.

## Problem-Solving Process

1. Understand the problem
2. Identify input
3. Identify output
4. Take a small example
5. Observe the pattern
6. Decide what information must be remembered
7. Write the approach
8. Dry run
9. Code
10. Test edge cases

## Main Learning

Some string problems require storing information about
characters instead of simply processing them one by one.
