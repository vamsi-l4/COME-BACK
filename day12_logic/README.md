## Main Concept

Queue:

First In -> First Out

Like people standing in a line.

## Python

Use:

from collections import deque

append() -> add to back
popleft() -> remove from front

## Stack vs Queue

Stack:
Last In -> First Out

Queue:
First In -> First Out
