Understand how sorting works and recognize sorting patterns.

## Topics
- Bubble Sort
- Selection Sort
- Insertion Sort
- Sort an Array
- Sort Colors
- Merge Sorted Array
- Relative Sort

## Main Patterns

Bubble:
Compare neighbors → swap

Selection:
Find minimum → place it

Insertion:
Take element → insert into sorted portion

Merge:
Already sorted arrays → compare using two pointers
